# Hi, I'm Anto

I build data-driven tools for volcanology and seismology, combining signal processing, machine learning, and practical software engineering to support monitoring workflows.

## What I work on

- Volcanic eruption forecasting from seismic data
- Seismic feature engineering (RSAM, DSAR, entropy)
- Event classification and monitoring pipelines
- Lightweight web tools and dashboards for scientific operations

## Featured Repositories

| Repository | Brief description | Stack |
|---|---|---|
| [eruption-forecast](https://github.com/martanto/eruption-forecast) | End-to-end volcanic eruption forecasting pipeline using seismic tremor data, feature extraction, and machine learning models to estimate eruption probability. | Python, ML, time-series |
| [dsar](https://github.com/martanto/dsar) | Python package for calculating Displacement Seismic Amplitude Ratio (DSAR) as a monitoring metric for volcanic activity. | Python, seismology |
